# ♞ שחמט קולני

שחמט מרובה משתתפים בזמן אמת (Node.js + Socket.IO + chess.js), בעיצוב בהשראת Chess.com — וכל כלי עושה קול כשהוא זז:

| כלי | קול |
|---|---|
| ♚ מלך | צחוק "הה-הה-הה" בסגנון המלך מקלאש רויאל |
| ♞ פרש | "HOG RIDERRR!" |
| ♜ צריח | צרחה |
| ♟ חייל | "אוף" בסגנון רובלוקס |
| ♝ רץ | התנשפות |
| ♛ מלכה | גניחה דרמטית |

הקולות מסונתזים בדפדפן (Web Audio), כך שאין צורך בקבצים. את הסאונד אפשר לכבות, לשנות עוצמה ולנסות כל קול בהגדרות (גלגל השיניים למעלה).

## רוצים את הקולות המקוריים?
הקטעים המקוריים מקלאש רויאל ורובלוקס מוגנים בזכויות יוצרים, ולכן הם לא כלולים. אם יש לכם קבצים משלכם, שימו אותם בתיקייה `public/sounds/` בשמות האלה, והם יחליפו אוטומטית את הקולות המסונתזים:

```
king.mp3  queen.mp3  rook.mp3  bishop.mp3  knight.mp3  pawn.mp3
```
(גם ‎.wav או ‎.ogg עובדים.)

## הרצה מקומית
```bash
npm install
npm start
```
ואז לפתוח http://localhost:3000 בשני חלונות.

## העלאה ל-Render
1. דוחפים את התיקייה ל-GitHub.
2. ב-Render: **New → Web Service** (או **Blueprint** — הקובץ `render.yaml` כבר מוכן).
3. Build: `npm install`, Start: `npm start`. ה-PORT נלקח אוטומטית מ-Render.

הערה: המשחקים נשמרים בזיכרון השרת, כך שהפעלה מחדש של השרת (או "הירדמות" בתוכנית החינמית) מוחקת משחקים פתוחים.

## מה יש
- חדרים עם קוד/קישור הזמנה, צופים, התחברות מחדש אחרי רענון
- חוקי שחמט מלאים בצד השרת: הצרחה, דילוג (en passant), הכתרה, מט, פט, תיקו (חומר לא מספיק, חזרה משולשת, 50 מסעים)
- שעונים עם תוספת זמן, כניעה, הצעת תיקו, משחק חוזר (מחליף צבעים), צ'אט
- גרירה או לחיצה להזזה, סימון מסעים חוקיים, מסע אחרון ושח
